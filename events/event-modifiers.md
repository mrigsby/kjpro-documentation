# Event Modifiers

## What is an event modifier?

An event modifier changes certain specifics for a single event date in an events schedule or completely removes if from the schedule.&#x20;

In all examples below we will use an example weekly event that is scheduled to occur every Monday between September 1, 2025 and December 1, 2025. Our example event would occur on the following dates:

`09/01/2025, 09/08/2025, 09/15/2025, 09/22/2025, 09/29/2025, 10/06/2025, 10/13/2025, 10/20/2025, 10/27/2025, 11/03/2025, 11/10/2025, 11/17/2025, 11/24/2025, 12/01/2025`

An event modifier can make a change to any specific date in this list of event dates.&#x20;

## Where do I manage event modifiers?

You can view and mange event modifiers from your `Event` listings page in the `Host Dashboard` by clicking the calendar icon in the `Event Modifiers` column for any specific event.
