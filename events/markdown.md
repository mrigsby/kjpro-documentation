# Managing Events

When navigating to the `Events` page form the dashboard menu you will be provided a list of all your active events. To view inactive events click the toggle button to the left of `include In-Active Events` and the list will refresh including in-active events.&#x20;

{% hint style="info" %}
In-Active event rows will be highlighted in red
{% endhint %}

<figure><img src="../.gitbook/assets/Screenshot 2025-09-16 at 12.38.43 PM.png" alt=""><figcaption></figcaption></figure>

The list includes the following columns. Some columns display pertinent information while others provide links to specific functions.

* Event Flyer: Thumbnail image of the provided event flyer. If no event flyer is provided it will display the default "No event flyer uploaded yet" image. If you click the thumbnail it will show a full size preview of the flyer.&#x20;
* Name: Pretty basic... The name of the event
* Schedule: Provides a synopsis of the set event schedule
* View: A clickable icon to open the "Root" event page in a new window or tab.
* Edit: A clickable icon to open the "Edit Event" page
* Event Modifiers: A clickable icon to open the mange even modifiers page for this event
* Event Photos: A clickable icon to open the manage event photos page for this event
* Set Status: A clickable icon that quickly toggles the event from Active to In-Active or In-Active to Active.
