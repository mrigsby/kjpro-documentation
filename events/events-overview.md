# Events Overview

KJPro.info supports two types of events

1. Single Events
2. Weekly Recurring Events

### Single Events

A single event is one that only occurs once on a specific date. A single event is used for events like fund raisers, special occasion, etc. Any event that only happens once.&#x20;

### Weekly Recurring Events

An event that happens every week on a specific day of the week. For example every Monday. The KJPro.info platform allows you to enter these once, select the date span it should be listed on the platform, the day of the week and it calculates all the dates in the event schedule.&#x20;

#### How do I handle events that arent every week, for instance an event thats only every 1st and 3rd Monday of each month?

The KJPro.info platform uses event modifiers to change specific dates in the events schedule. Event modifiers can do four things:

1. Cancel a specific event date and remove it from all search results
2. Cancel a specific event date and show a canceled message
3. Modify the Start and End Time, Title, Description and Specials for any single event date
4. Upload an alternate flyer for this single event

See the Event Modifiers section for more information.

#### Event Flyers

You can upload an event flyer that will be displayed in the search results as well as on the event page itself. A well designed and attractive event flyer is a great attention getter for your event!

{% hint style="info" %}
Note: Event flyers should be in standard image formats. .jpg is preferred.
{% endhint %}

### Once an event is saved it will immediately be included in the search results if the status is set to active.
